# TEGEN

TEGEN — Telegram Mini App + Telegram Bot + Admin Panel asosidagi onlayn do‘kon tizimi.

## Tuzilishi

- `apps/mini-app` — mijozlar uchun Telegram Mini App
- `apps/admin` — admin panel
- `apps/bot` — Telegram bot
- `server` — NestJS + Prisma API
- PostgreSQL — ma'lumotlar bazasi

## Asosiy imkoniyatlar

### Mijoz

- Telefon raqam orqali ro‘yxatdan o‘tish
- Mahsulotlarni ko‘rish
- Kategoriya bo‘yicha filter
- Mahsulot qidirish
- Chegirmalarni ko‘rish
- Savatga qo‘shish
- Miqdorni `+ / −` orqali o‘zgartirish
- Savatni saqlab qolish
- Buyurtma berish
- Buyurtma tarixini ko‘rish
- Buyurtma holati haqida Telegram xabarlari olish
- Admin bilan yozishish

### Buyurtma statuslari

1. 🆕 Yangi
2. ✅ Qabul qilindi
3. ⏳ Tayyorlanmoqda
4. 🟢 Tayyor
5. ❌ Bekor qilindi

Yetkazib berish tizimi mavjud emas.

### Admin

- Mahsulot qo‘shish
- Mahsulotni tahrirlash
- Mahsulotni o‘chirish
- Narxni o‘zgartirish
- Eski narx va chegirma
- Rasm
- Kategoriya yaratish
- Kategoriyani tahrirlash
- Kategoriyani o‘chirish
- Buyurtmalarni ko‘rish
- Buyurtma statusini o‘zgartirish
- Ishchilarni boshqarish
- Ishchi kategoriyasini biriktirish
- Ishchi takliflarini ko‘rib chiqish
- Statistika va tahlil
